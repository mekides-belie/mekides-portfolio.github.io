Research Projects

Research Assistant

Chris Callison Burch Lab UPenn (Multimodal AI Lab)

Project Details

Overview ▼

Developed a multimodal Retrieval-Augmented Generation (RAG) pipeline for scientific question answering leveraging text and image data from the Semantic Scholar API.

The Problem ▼

Researchers needed an efficient way to search and retrieve relevant scientific information from both text and visual content in academic papers, with high precision and reduced hallucinations.

The Solution ▼

Built a multimodal RAG system that processes PDFs into Markdown, encodes text-figure pairs with CLIP embeddings, and uses Weaviate with FlagEmbedding reranking for precise cross-modal retrieval.

Built With ▼
Python CLIP Weaviate FlagEmbedding PyTorch Semantic Scholar API
Lessons Learned ▼

Multimodal AI requires careful alignment between text and visual embeddings. Reranking significantly improves retrieval precision and reduces LLM hallucinations in scientific contexts.

Budgeting App

Personal Project

Project Details

Overview ▼

The Problem ▼

BiteMap

Personal Project

Project Details

Overview ▼

Built BiteMap, a map-first cheesesteak finder for web and mobile. It loads hundreds of nearby cheesesteak spots from Google Places, with filters, favorites, personal ratings, photos, and Google Maps directions. Every spot is marked with a cheese icon for quick scanning.

The Problem ▼

Students in Philly like myself needed a fast way to see all cheesesteak options in one place, without switching between multiple apps or doing inconsistent searches.

The Solution ▼

Created a server that queries Google Places with large-radius, multi-keyword searches, handles pagination, and removes duplicates. The app sorts results by distance and rating, and supports filters, favorites, user ratings, photos, and one-tap directions. Each location is clearly tagged with a 🧀.

Built With ▼
HTML CSS JavaScript React Native Node.js Express Google Places API

UniVo

Personal Project

Project Details

Overview ▼

A mobile app to help people find and discuss local volunteering opportunities. Users swipe through a feed of roles, open a discussion and organizers can post new opportunities.

The Problem ▼

Volunteer opportunities are scattered across many sources, making it hard for people to quickly find relevant roles. Organizers also need an easy way to share opportunities without heavy tools.
